Bean Growth v4.90

主要変更
1. ホーム画面をコンパクト化
- YOUR JOURNEYを1行中心の薄いカードへ
- TODAY'S EVENTを1行の状態バーへ
- 詳細説明はホーム下部の「基本ルール」に集約
- 特別の日 / 成長の風 / 成長の嵐 / 天豆の奇跡を色と短い文言で識別

2. プロフィールを独立
- 「個人記録」から公開プロフィールを分離
- ホームに「プロフィール」ボタンを追加
- 個人情報：Player ID、ニックネーム、アカウント作成日、最初の記録日、ログイン/Firebase状態
- 公開情報：目標、代表禁欲、最高高度、最高連続、図鑑解放数、深刻度
- 目標は最大80文字
- 公開プロフィールプレビューをプロフィール内に配置

3. 深刻度の開始ルール
- 各禁欲は最初の成功/失敗記録前にLIGHT / NORMAL / HEAVYを確認
- 記録開始前は設定画面からいつでも即時変更可能
- 最初の記録時に開始時深刻度を確定
- 開始後の深刻度変更は翌月1日適用
- ランキング途中参加への日数補正はしない
- 遡り編集で最初の記録を作る場合も深刻度確認を行う

4. データ
- 各禁欲にstartedAt / startSeverityを追加
- 既存データは最古の履歴日を開始日として移行
- schemaVersion 15
- dataRevision 16
