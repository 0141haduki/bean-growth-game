月の加護：
月（384,400km）への初到達時に一度だけ獲得。
次の失敗時に高さの減少を1回だけ自動で防ぐ。
ただし連続失敗回数は1増える。
一度消費すると再取得できない。

イベント暫定ルール：
- 毎月1日・15日：特別成長日 +10m
- その他の日：日付固定の8%抽選でゲリラ成長日 ×1.1
