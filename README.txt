Bean Growth Version 3.1

変更点
- 個別ページ上部に大型「今日も継続できた」ボタン
- 「今日は継続できなかった」は小型テキストボタンへ
- 高さ比較を milestones.js に分離
- 高さ比較データを大幅増量
- 現在地・次の目標・この先5件を表示
- 既存v3.0のイベント機能・開発者モードを維持
- localStorage保存キーは v1 のまま維持し、既存データを引き継ぐ

設置方法
1. index.html / style.css / script.js を既存ファイルと置き換える
2. milestones.js を新規追加する
3. 4ファイルを保存
4. Live Serverで index.html を開く
