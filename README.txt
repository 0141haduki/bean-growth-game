Bean Growth Version 4.30
==============================

v4.22〜v4.30をまとめた大型アップデートです。

【v4.22 称号用語を整理】
・「修飾語 / 名詞」という表示を廃止
・「前称号 / 後称号」に変更
・各禁欲専用の未獲得条件を明記
  例：
  「この禁欲で最高7日連続」
  ↓
  「オナ禁で最高7日連続」
  「ギャンブル禁で最高7日連続」
  「カフェイン禁で最高7日連続」

【v4.23 前称号を大幅増量】
・継続日数
・累計成功
・高さ
・特別成長日
・ゲリラ成長日
・失敗後の再起
・複数禁欲
・図鑑
・図鑑ミッション
から獲得する前称号を追加。
前称号は40種類超。

【v4.24 後称号を拡張】
・10種類の禁欲それぞれ通常8段階
・各禁欲のBLACK HISTORYは1個だけ
・複合禁欲8種類
・初期後称号1種類
自虐称号を増やしすぎないルールは維持。

【v4.25 称号コレクション強化】
・前称号 / 後称号タブ
・称号検索
・レアリティ絞り込み
・COMMON / RARE / EPIC / LEGENDARY別の獲得数
・獲得元と条件を表示

【v4.26 図鑑ミッション強化】
・山、都市建築、生物、自然、宇宙、天体、全体解放数など13ミッション
・一部ミッション達成で前称号を解放

【v4.27 図鑑拡張】
・図鑑を 376 件へ拡張
・山、建築、ランドマーク、生物、自然、宇宙、天体サイズなどを追加
・実在物ではない途中の「基準」は明確にゲーム内比較目盛りとして表示

【v4.28 詳細ページ強化】
カテゴリごとに比較値の意味を表示。
・建物：尖塔/アンテナ等の定義差
・生物：体長/全長と個体差
・天体：直径と高度の違い
・自然：落差/深さ/樹高
・宇宙：軌道と距離の変動
・基準：実在物ではないことを明示
山の危険度注意は山だけ。

【v4.29 継続分析】
個人記録に追加：
・記録日の成功率
・直近30日の成功率
・失敗後の平均復帰日数
・1日に同時成功した最大禁欲数

【v4.30 オンライン直前データ整理】
・schemaVersion 6
・バックアップ書き出し
・JSONバックアップ復元
・データ基本構造診断
・プロフィールのデータリビジョン
・既存ID / localStorageキーを維持

【既存仕様維持】
・10種類の禁欲
・表示 / 非表示
・休止 / 再開
・並べ替え
・前称号×後称号
・3種類 / 5種類の複合禁欲称号
・3連続失敗BLACK HISTORY
・月の加護
・カレンダー
・週間 / 月間レポート
・開発者モード
