Bean Growth Version 4.21
==============================

【重大不具合修正】
v4.20でボタンが押せず、画面切替もできなくなる問題を修正しました。
原因は、JavaScript起動直後に「まだ初期化されていない称号キュー／図鑑ミッション定数」を参照していたことです。
初期化の実行位置をファイル末尾へ移し、全関数・定数・ボタン登録の準備後に起動するよう変更しました。
また、古い保存データで settings が無い場合の移行順も修正しました。

【複合禁欲称号 8種類】
「同じ複数の禁欲を、同じ日々に並行して守る」実績を追加しました。
単に別々の時期に達成した最高連続日数を足すのではなく、同じ禁欲の組み合わせが同じ連続日で成功していることを判定します。

■ 3種類以上を同時継続
3日  COMMON     三道の挑戦者
7日  RARE       三道の守り手
30日 EPIC       三欲を制する者
100日 LEGENDARY 三道の覇者

例：オナ禁・ギャンブル禁・カフェイン禁を3日間すべて成功
→ 「三道の挑戦者」を獲得

■ 5種類以上を同時継続
3日  COMMON     五道の挑戦者
7日  RARE       五道の守り手
30日 EPIC       五欲を制する者
100日 LEGENDARY 五道の覇者

【称号システムとの連携】
・8種類は名詞称号として永久解放
・既存の修飾語と自由に組み合わせ可能
例：「意志が強い 三道の守り手」
例：「月に選ばれし 五道の覇者」
・称号工房に「🤝 複合禁欲」フィルターを追加
・獲得元は「複合禁欲」と表示

【自虐称号】
v4.20の各禁欲1個・合計10個のBLACK HISTORY称号はそのまま維持します。

【データ互換】
v4.20以前のデータを引き継ぎます。
localStorageキーは変更していません。
