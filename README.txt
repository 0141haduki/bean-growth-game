Bean Growth Version 4.59
=========================

v4.50〜v4.59 一括アップデート

v4.50 未記録ルール
- 未記録日は成功でも失敗でもない
- 高さと連続失敗回数は変化しない
- 未記録日を挟むと成功ストリークは途切れる
- 期限内に遡って成功へ変更した場合はストリークを再計算

v4.51 遡り記録
- 今日を含めて3日間のみ編集可能
- 最大2日前まで
- 3日前以前は確定済み

v4.52 リワード編集ルール
- 今日：通常編集
- 昨日：通常編集
- 一昨日：リワード広告で編集解放
- 広告SDK接続前は開発用テスト解放で動作確認可能

v4.53 履歴再計算
- 過去2日を変更した場合、高さ・連続成功・連続失敗・イベント効果を時系列で再計算
- 未記録の空白日を正しくストリーク切断として扱う

v4.54 月間ランキング確定ルール
- 月末2日分の遡り修正を考慮
- 前月ランキングは翌月3日に確定・発表する仕様をデータ/UIへ反映

v4.55 記録率
- カレンダーに記録率を追加
- 成功/失敗/未記録を分離

v4.56 個人曜日分析
- 曜日別の成功・失敗・未記録
- 曜日別失敗率・記録率

v4.57 リセット分析
- 3連続失敗による0mリセットを曜日別に集計
- 危険曜日・安定曜日・リセット最多曜日を表示

v4.58 グローバル分析準備
- Firebaseクラウド保存時に匿名集計用analyticsContributionを保存
- 曜日・月内日付・禁欲別の成功/失敗/リセット件数を準備

v4.59 分析UI・データ移行
- PERSONAL ANALYTICS / GLOBAL ANALYTICSをランキングとは別系統で準備
- グローバル統計は参加ユーザー数・記録件数・リセット件数の母数明記を前提
- schemaVersion 10 / dataRevision 5

重要:
- 実広告（AdMob等）のリワード配信は未接続。現在はテスト解放。
- グローバル集計の全ユーザー横断処理はv5系サーバー実装で有効化。
- localStorageキー beanGrowthGame_v1 は維持。
