【カテゴリ変更】
🍪 間食禁 → 📺 娯楽動画禁 に変更。

娯楽動画禁は、YouTubeなどの長尺娯楽動画、ライブ配信、娯楽目的の動画サイト視聴を控えるカテゴリです。
ショート動画禁とは別枠なので、
・🎞️ ショート動画禁 = Shorts / TikTok / Reels
・📺 娯楽動画禁 = 通常の長尺動画 / 配信 / 娯楽視聴
として使い分けられます。

内部ID noSnacking は互換性のため変更していません。
旧「間食禁」に記録があった場合、その高さ・履歴は「娯楽動画禁」へ引き継がれます。
